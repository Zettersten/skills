# Example: "MyMod" floating target bar

A minimal, self-contained custom window that shows the current target's name (con-coloured), a red health bar,
a digital percentage, and faces the target when you click the name. It uses user window slot 1
(`custom1_window`, opened by the `ToggleCustom1` event).

Status: written against the documented and observed syntax and linted clean. It has **not** been launched in a
live client from this machine; expect to nudge pixel positions.

## Files

| file | role |
|---|---|
| `custom/MyMod_Assets.xml` | declares the texture sheet and five templates (9-slice dialog, bar track, bar fill, status bar, button). Depends on nothing from the stock skin except the `arial9` font. |
| `custom/custom1_window.xml` | the window template `custom1_window` |
| `custom/mymod_01.tga` | 128x64 texture sheet, generated by `make_example_texture.py` |
| `command_window.snippet.xml` | the two pieces to paste into your copy of `command_window.xml`: the `<Include>`s and a toggle button |
| `make_example_texture.py` | regenerates the TGA (pure Python) |

## Install

1. In `<game>\ui\`, create `custom\` (and `custom\oldstyle\`) if they do not exist.
2. Copy `custom/MyMod_Assets.xml`, `custom/custom1_window.xml`, `custom/mymod_01.tga` into `<game>\ui\custom\`.
3. Copy the stock `<game>\ui\atlantis\command_window.xml` to `<game>\ui\custom\command_window.xml` (only if you
   do not already have one) and paste the two pieces from `command_window.snippet.xml` into it:
   the `<Include>`s at top level, the `<ButtonDef>` inside the `command` window template after its background.
   If the button lands under an existing `InvisibleButtonDef`, move it or place it later in the file.
4. Lint: `python ../scripts/daoc_ui_lint.py <game>\ui\custom --base <game>\ui\atlantis`
5. Start the game, at character select open Options and set the interface skin to **Custom**, log in, press the
   new "Target" button in the command window. Drag the bar where you want it; the position is saved per character.

Already running BobsUI or Bysan? Skip the command window: add the two `<Include>` lines to their `assets.xml`
and put the `ToggleCustom1` button in their main menu window instead, choosing a free slot number
(BobsUI uses all 20; renumber the file, the template `Name` and the event together, e.g. `custom19_window`).

## Why it is shaped this way

- No `assets.xml` is shipped. A `custom/assets.xml` replaces the stock one entirely, taking every stock font and
  texture with it. Loading the mod from a file you already override (`command_window.xml`) avoids that.
- Templates are private (`*_mymod_*`) so nothing breaks when a patch renames stock templates.
- `summary_target_hits` is a 0-100 scalar, so the same adapter drives the `StatusBarDef` and the `ScalarLabelDef`.
- The `InvisibleButtonDef` is last so it is on top of the label it covers. Draw order is XML order.
- `DontDrawWhenNegOne` hides the readout when there is no target (the adapter reports -1).
