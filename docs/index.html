CLI Tools

#1

httpie

cli http api

Make HTTP requests using the HTTPie CLI (http and https commands). Covers request syntax, authentication (basic, bearer, digest), file uploads, downloads, sessions, streaming, and common REST patterns. Includes scripts for scraping, health checks, and no-admin installs.

Requires httpie ≥ 3.0  ·  brew install httpie

$ npx skills add Zettersten/skills/httpie

UI & Visual Effects

#2

liquid-glass

css svg ui react

Implement Apple's Liquid Glass UI effect (iOS 26 / macOS 26) using CSS and SVG feDisplacementMap filters. Covers the four-layer composition model, displacement map generation (SDF and Snell's law modes), ready-to-use HTML and React templates, and chromatic aberration. Full physics deep-dive included.

Full effect in Chrome/Edge  ·  Blur fallback in Firefox & Safari

$ npx skills add Zettersten/skills/liquid-glass
